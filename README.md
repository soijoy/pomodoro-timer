# 🍅 ポモドーロタイマー

シンプルなブラウザ完結型のポモドーロタイマーです。作業・短休憩・長休憩の3モードを切り替えながら、完了したセッションの履歴と集計を記録できます。

## 特徴

- 作業(25分)/ 短休憩(5分)/ 長休憩(15分)の3モード
- 円形プログレスリングによる残り時間の可視化
- 現在取り組んでいるタスク名の入力
- セッション履歴と今日/合計の完了数を `localStorage` に保存
- セッション完了時にビープ音で通知

## 使い方

### そのまま開く

`index.html` をブラウザで直接開くだけで動作します。

### ローカルサーバーで開く(推奨)

`localStorage` の挙動をより実環境に近い形で確認したい場合は、同梱の PowerShell 製の簡易サーバーを使えます。

```bash
pwsh server.ps1
```

起動後、ブラウザで `http://localhost:8080/` にアクセスしてください。

## テスト

時間表示のフォーマット処理(`timeFormat.js`)に対する簡単なユニットテストを用意しています。

```bash
npm test
```
